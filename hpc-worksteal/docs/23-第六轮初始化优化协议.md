# 第六轮：保持身份不变的内存初始化优化

2026-10-21，筛选前冻结。第五轮完成后从真实阶段数据确定memory初始化为候选优化对象。本轮只修改内存数据填充；不改调度运行时、策略、执行递推、完整参考核验、顺序FNV或计时边界。

## 实现契约

measurement.initialization_workers默认1，仅整数1..128合法。原主线程vector分配与清零保留。内存任务按连续完整元素块划分，active=min(请求线程数,N)，每个线程只写自己的data区间，每个值仍为原mix(seed+全局word下标)，uint64自然回绕。active≤1保留原连续循环；非内存任务used=0。初始化线程继承控制线程掩码；不宣称物理绑核。初始化线程不使用被测Pool，全部join后才生成身份、创建Pool和进行原home worker预读。

闭包与数据生存期长于jthread容器；创建线程失败时先join再销毁成员，填充体无分配或可抛异常操作。无共享可变游标，每线程独占区间，join发布数据。未注入线程创建失败，只依据RAII语义说明该路径。

主线程清零、填充、线程创建/join仍计入workload_initialization及app；identity_hashes仍逐字节顺序遍历原数据。分配/首次清零与逻辑home预读保持，但填充线程可能改变缓存状态，因此本轮比较整体应用干预，不能声称只测纯生成器速度或保证物理驻留相同。不缓存核验答案或省略任何散列。
