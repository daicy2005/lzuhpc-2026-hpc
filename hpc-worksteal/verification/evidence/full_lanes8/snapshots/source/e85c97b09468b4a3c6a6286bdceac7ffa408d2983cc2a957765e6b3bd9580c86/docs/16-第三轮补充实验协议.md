## R3A 筛选

复用第二轮已验证、散列一致的 Release 二进制。正式运行前重新执行所用三个构建的 runtime_checks 和当前独立 Python CLI oracle。seed=811，N=262144；light K16，uniform/skewed K1024；skewed concentrated。每条件一预热、三次计时，独立进程；固定随机条件顺序并逐块轮换，保留所有慢成功记录。

- light：p16，构建 runtime/lanes8/full_lanes8，grain256/512/1024/4096，共12条件。
- uniform：lanes8，p16/24/32，grain1024/2048/4096/8192，共12条件。
- skewed：full_lanes8，p16/24/32，grain256/512/1024/2048，共12条件。

每类包含第二轮现推荐参数。选最小 epoch 中位数，ID破同分；这仍是局部组合搜索，不叫全局最优。共36条件、144进程、108计时。单批600秒、单进程90秒，错误或超时保留并停止，不追跑到通过。

## R3B 新输入确认

候选只允许来自R3A预定选择。对照为第二轮当前推荐构建/worker/grain，不是原始慢基线。seed601/3001，N229376/360448，K及布局保持。每输入预热后5对AB/BA交替；两输入均须至少4/5对更快，且候选中位数不超过对照95%，否则保留第二轮推荐。不追加样本、不选第二名、不使用本轮留出继续调参。候选完全等于当前推荐时不运行重复对照，记为筛选保留。最多72进程、60计时。该工程门槛不是统计显著性检验。

身份核对：同输入的input/cost/data/output散列和total_cost必须一致；同任务划分/worker条件还核对task/queue身份。保存计划、源码ID、构建ID、实际命令、环境、每次结果和完整校验清单。旧构建的来源仍指向第二轮evidence/opt-*，采集器快照单独保留。
