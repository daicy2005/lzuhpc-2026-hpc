2026-10-21，正式性能计时前冻结。第六、七轮原件封存，不追加样本；本轮不采用它们未过门槛的候选。新的唯一候选为measurement.memory_lanes=4，对照1，省略默认1。只接受整数1/4。相同新二进制、相同任务集合、worker16/grain4、zeroed分配、填充线程1、完整标量参考线程4。

## 工作量与实现契约

原memory执行内核逐元素处理，单个元素的每一步依赖上一步。候选对任务内连续4个独立元素交错：pass→word→lane。每个元素仍按完全相同的pass/word顺序进行原uint64递推；每次读取相同数据，次数不变，不缓存跨pass答案。尾部少于4元素仍用原标量value()；不跨任务合并，不修改任务home、窃取、完成计数、预读、初始化、顺序FNV或独立参考value()/verify()。跨元素访存顺序会改变，不能声称缓存状态相同。

该方案是CS149的独立工作并行与延迟隐藏：暴露指令级并行，编译器可能进一步向量化，但未看汇编或计数器前不声称具体SIMD实现或缓存因果。即使epoch改善也属于执行内核收益，不称为工作窃取策略收益；不与历史轮次倍数相乘。
