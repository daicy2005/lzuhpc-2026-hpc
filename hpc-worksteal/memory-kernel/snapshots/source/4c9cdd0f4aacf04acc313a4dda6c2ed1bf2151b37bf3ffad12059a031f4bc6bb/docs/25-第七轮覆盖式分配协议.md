# 第七轮：省掉被完整覆盖的清零

2026-10-21，所有正式计时之前冻结。本轮从第六轮阶段数据继续分析；顺序FNV存在逐字节递推依赖，本轮不改散列算法或并行合并。只研究memory存储的重复清零，保持全部输入生成与执行工作量。

## 实现及正确性契约

measurement.data_allocation可省略，默认zeroed；仅字符串zeroed/overwrite合法。两者均在控制线程分配相同长度的uint64_t数组，zeroed用make_unique值初始化，overwrite用C++20 make_unique_for_overwrite开始对象生命周期而不值初始化。每个word随后都按原mix(seed+全局word下标)生成；完整填充及join之前不读数据、不散列、不启动Pool。空memory与compute不分配数组，used=none。唯一所有权释放存储；线程创建异常时仍先join再析构成员，没有故障注入证明。

身份散列只将原vector接口改为只读span；字节顺序、FNV常量和递推不改。所有身份字段、总字节数、执行递推、原始独立标量参考核验、顺序输出散列及逻辑home预读保留。不缓存答案，不把散列移出计时。分配、完整生成、首次写入仍计入workload_initialization和app，epoch及app边界不变。本轮允许省去冗余清零，不能宣称物理驻留或缓存状态相同。

新Release(full_lanes8：completion32/scratch/LTO/lanes8)、ASan/UBSan、TSan分别构建并完整检查。覆盖两种分配、空/单元素/不整除分区/线程多于元素、多epoch、8/136/8192字节宽度、uint64种子回绕与非法参数。独立Python逐word重算数据、输入、输出和预读FNV；ASan/UBSan不是未初始化读取检测器，TSan也不是。覆盖安全依据完整写入区间证明与独立oracle，不声称通过MSan。

## 固定候选、确认与停止

不另做筛选，唯一预先指定候选overwrite，对照zeroed。沿用configs/verified/memory执行配置，填充线程固定1、参考线程固定4，其他参数相同。两个未用过的确认输入seed31013/N80块(40MiB)、seed37003/N120块(60MiB)，每块512KiB、16passes。

先做12个control：四类任务×第六轮Release/新zeroed/新overwrite。seed29009，compute N4096，memory N64；旧二进制省略新字段。control只验证完整身份/输出/预读一致，不进入性能统计。随后每输入每条件1次预热；各输入7对AB/BA，奇数对base→candidate、偶数对反向；两个输入顺序由Random(2026102108)打乱后冻结。

总44研究进程=12control+4预热+28正式计时；不追加/重选/追跑。两输入都至少6/7对app更快且候选app中位数≤对照95%才采用。本门槛不是统计显著性检验；否则保留zeroed与旧推荐。通过后新存configs/overwrite，默认仍zeroed以保留兼容基线，不修改configs/verified历史配置。
