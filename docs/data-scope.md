# 实验记录说明

仓库收录了报告引用的 24 次光追计时、663 次 WorkSteal 计时，以及 12 次分阶段测试。随机 victim 实验还包含预热和诊断，共运行 114 次，其中 84 次用于性能比较。

可以通过 `report/evidence-index.json` 找到文中结果对应的运行目录，查看参数、命令、日志和输出检查。未被报告引用的其他历史实验仍保存在本地。

`MATERIALS-MANIFEST.json` 列出了原项目文件的路径、大小和 SHA256。运行 `python3 tools/verify_materials.py` 可检查文件是否完整，并核对上述计时记录；这个脚本不会重新跑性能实验。

PDF 中的链接指向与报告对应的代码和数据版本。
