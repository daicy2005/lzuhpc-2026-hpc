# 数据范围

本次分享树保留报告核对的 24 份光追正式对照、663 份 WorkSteal 正式记录，以及 12 份独立阶段观测。第十六轮恢复批次的全部 114 个进程记录单独保留，计时、诊断和预热不混合统计。

这不是全部历史实验的公开镜像。其他历史原件与旧提交包继续保存在本地，不删改；不能因本仓库未收录就称其不存在。所选结果可由 `report/evidence-index.json` 定位到原始 run，再按各目录的 checksums 核对。工作集、输出一致性、输入身份与计时定义均沿用原始记录。

`MATERIALS-MANIFEST.json` 列出从原项目复制的文件、来源、大小和 SHA256；本地准备收据记录凭据模式扫描结果。源码、配置和数据按原字节复制，`.gitattributes` 关闭自动换行转换，避免原始散列因 Git checkout 被改写。

评阅时请使用 PDF 中的固定版本链接。仓库首页用于导航，固定提交用于确定本次报告对应的代码、附录和数据版本。连续对话与 Session 导出文件未包含在本仓库中。
